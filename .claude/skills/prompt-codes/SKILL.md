# 프롬프트 단축 명령
| 명령 | 답변 방식 |
|---|---|
| /godmode | 결론부터 말하고 근거와 설명은 뒤에 |
| /devil | 확실하지 않은 건 단정하지 말고 확인된 사실과 추정을 구분 |
| /10x | 지금 것을 아이디어·구조·표현 모두 10배 낫게 개선 |
| /pitch | 핵심만 짧고 설득력 있게 |
| /ghost | AI 티가 나지 않게, 사람이 쓴 것처럼 자연스럽게 |
| /compare | 여러 선택지를 장단점 표로 비교 |
| /scout | 계획·아이디어의 문제점과 위험 요소 찾기 |
| /ooda | 복잡한 것을 관찰→판단→결정→행동 순서로 풀기 |
| /artifacts | 문제점을 고친 더 나은 버전을 바로 만들어 주기 |
| /critique | 부족한 점과 개선할 부분을 솔직하게 |
| /explainlikeim5 | 초등학생도 이해하게 아주 쉽게 |
| /brief | 핵심만 몇 줄로 요약 |
| /teacher | 선생님처럼 단계별로 차근차근 |
