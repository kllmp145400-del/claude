# Arena: 게시물 후보 대결

한 게시물에 대해 **서로 다른 5명의 선수**가 후보를 하나씩 내고, **심판**이 아래 채점표로 점수를 매겨 우승안을 고른다. 마지막에 우승안을 다듬어 플랫폼별 최종본을 낸다.

## 0. 입력 확인
사용자에게서 다음을 확인한다. 없으면 대화와 사진에서 찾고, 그래도 없으면 짧게 묻는다.
- 게시물 종류: 맛집 / 한국어 카드 / 중국어 고쳐주세요 / 영상(재미) / OOTD
- 플랫폼: 더우인, 샤오홍슈, 둘 다
- 사실 정보: 가게 이름·지점·방문 날짜·가격·인원·메뉴별 점수 (맛집이면 필수)
- 이미 쓴 초안이 있으면 그것도 선수 1명으로 출전시킨다.

**지어내지 않는다.** 가격, 날짜, 메뉴, 점수, 사연은 사용자가 준 것만 쓴다.

## 1. 선수 5명 (각자 제목 + 표지 문구 + 본문 + 고정 댓글 1세트)
| 선수 | 관점 |
|---|---|
| A 데이터파 | 계정에서 실제로 잘 된 형식을 그대로 따른다 (8문장 카드 10.7만, 엄마의 맛 1.5만, 고쳐주세요 댓글 148) |
| B 밈파 | 지금 유행하는 밈·표현을 탄다 (예: "欧巴让你为难了吗") |
| C 감정파 | 청두에 사는 한국인의 실제 감정·에피소드로 끈다 |
| D 저장파 | 정보·리스트·"先收藏"으로 저장을 노린다 |
| E 댓글파 | 투표(扣1/扣2)·질문·맞히기로 댓글을 노린다 |

## 2. 채점표 (100점)
| 항목 | 점수 | 기준 |
|---|---|---|
| 첫눈 후킹 | 20 | 피드에서 1초 안에 멈추게 하는가. 표지 문구가 크게 읽히는가 |
| 계정 정체성 | 15 | 제목이 `190cm`로 시작, "청두 사는 한국인 + 한국어" 콘셉트와 맞는가 |
| 저장 유도 | 15 | "先收藏⭐"·정보 카드·리스트가 있는가 |
| 댓글 유도 | 15 | 본문 끝이 중국인이 답하고 싶은 질문/투표인가 |
| 플랫폼 적합 | 15 | 더우인=짧고 빠르게, 샤오홍슈=스토리·정보 정리. 제목 20자 이내(이모티콘 1개, 2자로 계산) |
| 규칙 준수 | 20 | 아래 금지 사항을 하나라도 어기면 0점 |

**금지 사항 (어기면 규칙 준수 0점, 우승 불가)**
- 지어낸 이야기·가격·날짜
- 위챗 ID, 전화번호, 오프라인 만남 모집, 과외 홍보 문구를 맛집 토픽 글에 넣기
- 더우인 `#成都美食发现官` 토픽 글에 "团购/优惠/券" 같은 할인·판매 홍보
- 성적인 뉘앙스(擦边)로 끄는 표현
- 아이돌 실명 해시태그
- 얼굴에 글자가 겹치는 표지

## 3. 해시태그 규칙
- 더우인 **5개**, 샤오홍슈 **10개**, `#190cm`는 항상 맨 마지막.
- 맛집 글은 더우인에 `#成都美食发现官`을 맨 앞에.
- 조회수 0이거나 목록에 없는 태그는 쓰지 않는다. 너무 큰 태그(수십억)만 몰지 말고 수만~수천만 태그를 섞는다.
- Qovia 커넥터가 있으면 후보 태그의 실제 조회수를 확인한다. 없으면 사용자에게 앱 목록 캡처를 요청한다.

## 4. 출력 형식
1. **대결표**: 선수별 제목 한 줄 + 항목별 점수 + 총점 (표 1개)
2. **우승안과 이유**: 2~3줄. 다른 선수의 좋은 요소를 섞었다면 무엇을 가져왔는지
3. **최종본 (복사용 코드 블록)**
   - 더우인: 제목 / 본문+해시태그 / 고정 댓글 / 올리는 시간
   - 샤오홍슈: 제목 / 본문+해시태그 / 고정 댓글 / 앨범 / 올리는 시간
   - 중국어 문장 아래에는 한국어 뜻을 괄호로 붙인다.
4. **올리기 전 체크** 3줄 이내 (위치 비우기, 이벤트 빼기, 파란 태그 확인 등)
